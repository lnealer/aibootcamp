# Hello World Console Application

A simple Spring Boot console application using Java 17 and Spring Boot 3.2.0.

## Requirements
- Java 17 or higher
- Maven 3.x

## Build the application
```bash
mvn clean package
```

## Run the application
```bash
mvn spring-boot:run
```

Or run the JAR directly:
```bash
java -jar target/hello-world-console-1.0.0.jar
```

## Expected Output
```
Hello World!
This is a Spring Boot console application running on Java 17
```
